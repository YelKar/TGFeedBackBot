# Чеклист теста TGFeedBackBot

## 1. Предложка (юзер → бот в личке)
- [ ] Текст без форматирования → карточка `От @user` в админ-чате
- [ ] Текст с форматированием (жирный, цитата `<blockquote>`, `pre`) → сохраняется
- [ ] Фото/видео с подписью **снизу** → карточка-статья с каруселью
- [ ] Фото с подписью **сверху** (`show_caption_above_media`) → подпись над каруселью
- [ ] Альбом из 2-3 фото с **одной** общей подписью → одна статья-карусель
- [ ] Альбом с **двумя подписями** → отказ `⚠️ У альбома должна быть одна общая подпись`
- [ ] Документ/аудио — уходит как документ, не как статья

## 2. Голосование (админы)
- [ ] Кнопки 1-5 → `Голос N принят`, карточка показывает `Оценки: ...` и прогноз
- [ ] `/vote 5` реплаем на карточку → то же
- [ ] `/vote@BotName 5` → работает
- [ ] Переголосование (изменить оценку) → обновляется
- [ ] Авто-переход `pending → scheduled/rejected` по порогу
- [ ] Гонка: два админа жмут одновременно → без `CPU limit`, статус консистентен

## 3. Управление постом (реплай на карточку)
- [ ] `/edit Новый текст с **жирным**` → карточка обновляется, форматирование остаётся
- [ ] `/edit@BotName` → работает
- [ ] `/remove_photo 1` (один пост) → без номера тоже удаляет
- [ ] `/remove_photo 2` → удаляет 2-е, карточка обновляется
- [ ] `/add_photo 1` → `Пришлите фото` → отправка фото → вставляется на позицию 1
- [ ] `/add_photo` без номера → в конец (до 10)
- [ ] `/cancel_add` → отменяет ожидание
- [ ] `/ask Текст вопроса` → юзеру в личку приходит статья `<h4>Сообщение от модератора</h4>` + текст + футер, юзер отвечает reply → в админ-чат `Ответ автора`
- [ ] Ответ автора — без `blockquote`, с `h4` + ссылкой на пост в футере, с воздухом
- [ ] `/schedule` → `📅 ОДОБРЕНО`, попадает в очередь
- [ ] `/reject` → `❌ ОТКЛОНЕНО`
- [ ] `/publish` → мгновенно в канал `@qw...` + `🎉` юзеру + `✅ ОПУБЛИКОВАНО` в карточке
- [ ] `/block` → юзер в `blocked_user`, повторные предложения игнорятся
- [ ] `/use` реплаем на сообщение → создаётся предложка из него
- [ ] `/use Текст\nс переносом` без реплая → форматирование сохраняется

## 4. Очередь и списки
- [ ] `/queue` → `📊 Очередь (N)` с разбивкой по дням, ссылками `🔗`
- [ ] `/queue_p` → то же, но эфемерно только себе + команда удаляется
- [ ] `/waiting` → `h3` заголовок, `h4 @автор` **один на автора** (группировка), без списка если пост один: `🔗 <url> — дата`, иначе `<ol><li>…`
- [ ] В `waiting` вторая строка `не оценили: @...` — теперь с `<mark>` и **на каждый пост отдельно**
- [ ] `/waiting_p` — эфемерно себе, `waiting_my` — каждому админу его неоценённые (команда удаляется)
- [ ] `/reschedule` → `Очередь обновлена` + сразу вывод очереди (было пусто — теперь с очередью)
- [ ] `/reload` реплай → карточка перерисовывается из БД + тост `Карточка обновлена` (эфемерно)
- [ ] `/resend_missing` → переотправляет потерянные карточки (`admin_msg_id IS NULL`)

## 5. Публикация и надёжность
- [ ] Крон каждую минуту публикует due-посты, `Time Travel` в D1 включён (30 дней)
- [ ] D1 таймаут → `⚠️ D1 таймаут` без паузы, повтор на след. минуте
- [ ] Ошибка канала (`chat not found`) → 3 попытки → `⏸ Публикация ПРИОСТАНОВЛЕНА`, `/resume_publish` снимает
- [ ] После контента — пустая строка перед `Статус:` (в статье `<br/><br/>`, в обычном `\n\n`) — не сливается
- [ ] Переносы `\n` и `\n\n` внутри цитат — 2 переноса, не 3

## 6. Справка и приватность
- [ ] `/help`, `/help_p`, `/start`, `/start_p` — статьи с `h4` + `details open`, без капса и без `<code>`, команды plain
- [ ] Любая команда с `@BotName` суффиксом (`/edit@BotName`, `/vote@BotName`) — работает
- [ ] `help_p`/`queue_p`/`waiting_p` — видно только вызвавшему
