# 1. Общая концепция

Система — это **бот предложки Telegram-канала с автоматическим и ручным планированием публикаций**, управляемым через Mini App.

Принципы:

* Telegram-бот — **транспорт и уведомления**
* Вся логика — в Cloud Function + YDB
* Все публикации — **события**
* Расписание — **мягкое**, но строго соблюдает ограничения
* Администратор **всегда видит итоговое расписание**
* Администратор **всегда может вмешаться**

---

# 2. Роли и функционал

## 2.1 Пользователь (отправитель цитаты)

  * «Опубликовано»

* Не видит расписание
* Не управляет публикацией

## 2.2 Администратор (модератор)

### Через Telegram (Inline KB):

* Одобрить цитату
* Опубликовать сейчас

### Через Mini App:

* Смотреть очередь цитат

* Управлять конкретной публикацией:

  * Опубликовать сейчас
  * Отклонить
* Планировать публикации вручную
* Настраивать правила расписания

# 3. Сущности и модели данных

---

## 3.1 Quote (Цитата)

```sql
quote_id           UUID (PK)
text               String
author_name        String?
author_user_id     Int64
author_username    String
status             Enum(
    pending,
    approved,
    rejected,
    archived,
    published
)
created_at         Timestamp
approved_at        Timestamp?
```

Назначение:

* Основная сущность контента
* Не содержит времени публикации напрямую

---

## 3.2 PublishEvent (Событие публикации)

```sql
event_id           UUID (PK)
quote_id           UUID (FK)
type               Enum(auto, manual, scheduled)
publish_at         Timestamp
status             Enum(planned, done, cancelled)

preferred_time     Time?       -- исходный якорь (для auto)
created_at         Timestamp
```

Назначение:

* **Единственный источник истины** о публикациях
* Любая публикация — это событие

---

## 3.3 ScheduleRules (Глобальные правила расписания)

```sql
rule_id                  UUID (PK)
timezone                 String

daily_limit              Int32
preferred_times          List<Time>

earliest_publish_time    Time      -- например 08:00
latest_publish_time      Time      -- например 21:00

pre_cooldown_minutes     Int32
post_cooldown_minutes    Int32

auto_enabled             Bool
```

Назначение:

* Управляет авто-публикациями
* Используется планировщиком

---

## 3.4 Message (Диалог с пользователем)

```sql
message_id        UUID (PK)
quote_id          UUID (FK)
from_admin        Bool
text              String
created_at        Timestamp
```

Назначение:

* Общение админа с автором цитаты
* История переписки

---

## 3.5 AdminAction (опционально, для логов)

```sql
action_id         UUID
admin_user_id     Int64
action_type       Enum(
    approve,
    reject,
    publish_now,
    schedule,
    cancel
)
quote_id          UUID
created_at        Timestamp
```

# 4. Правила планирования и публикаций

---

## 4.1 Общие принципы

* Публикация возможна **только** в рамках:

  * временных границ дня
  * кулдаунов
* Дневной лимит — **цель**, но не обязанность
* Кулдауны **никогда не нарушаются**
* Scheduled публикации имеют приоритет над auto

---

## 4.2 Временные границы

```
earliest_publish_time ≤ publish_at ≤ latest_publish_time
```

Применяются ко всем публикациям.

---

## 4.3 Кулдауны (pre / post)

Для каждой публикации создаётся запретная зона:

```
[publish_at - pre_cooldown, publish_at + post_cooldown]
```

Внутри зоны:

* нельзя публиковать ничего другого

Работает:

* до scheduled
* после manual
* между auto

---

## 4.4 Автопланирование (мягкое)

Алгоритм на день:

1. Собрать все planned / done события дня
2. Построить запретные зоны
3. Посчитать `remaining = daily_limit - count(events)`
4. Для каждого `preferred_time`:

   * проверить конфликт
   * если конфликт → сдвигать вперёд
   * соблюдать границы дня
5. Остановиться, если:

   * время закончилось
   * remaining = 0

---

## 4.5 Ручное вмешательство

### Опубликовать сейчас

* Создаёт `PublishEvent(type=manual, publish_at=now)`
* Отменяет ближайшее auto-событие
* Пересчитывает расписание дня

### Запланировать вручную

* Создаёт `PublishEvent(type=scheduled)`
* Блокирует auto вокруг себя

# 5. Интерфейсы

---

## 5.1 Telegram Bot

### Пользователь:

* принимает цитаты
* уведомляет о статусе

### Администратор:

* inline кнопки:

  * Одобрить
  * Опубликовать сейчас
  * Отклонить
  * Открыть Mini App

---

## 5.2 Mini App (React)

### Экран «Очередь»

* pending / approved цитаты
* действия:

  * Одобрить
  * Отклонить
  * Назначить время

---

### Экран «Расписание дня»

* список публикаций:

  * время
  * тип (auto / manual / scheduled)
  * пометка «сдвинуто»
* кнопки:

  * Опубликовать сейчас
  * Отклонить

---

### Экран «Настройки»

* лимит в день
* preferred times
* pre / post cooldown
* границы публикаций
* включение / выключение авто
